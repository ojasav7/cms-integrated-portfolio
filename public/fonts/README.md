# Self-hosted fonts

Place `HelveticaNeue-Roman.otf` in this folder — it is referenced by the
`@font-face` rule in `src/styles/app.css` and served at `/fonts/HelveticaNeue-Roman.otf`.

Until the file is added, the `.font-helvetica-neue` Measured wrapper falls back
to `'Helvetica Neue', Helvetica, Arial, sans-serif`.
